# Fanpage Gemini Chatbot (Tiệm Kẹp Xinh)

Hệ thống chatbot thông minh, tự động hóa trả lời Fanpage Facebook bán hàng kẹp tóc bằng mô hình Gemini 3.6 Flash, lấy dữ liệu động từ Google Sheets với chi phí vận hành 0 VNĐ.

## Cấu trúc bảng Google Sheets
Bảng tính gồm 8 cột tiêu đề:
`ma_sp` | `ten_san_pham` | `chat_lieu` | `mau_sac` | `gia` | `link_anh` | `tinh_trang` | `dac_diem`

Link xuất CSV: Đổi đuôi `/edit?usp=sharing` thành `/export?format=csv`.
